## 4. 용어
- **남은 권수**: 보유 권수 − 대여 중인 권수. 0이면 대여할 수 없다.
- **대여(Loan)**: 사용자·도서·대여일·반납 기한·반납일·연장 여부. 반납일이 없으면 "대여 중".
- **반납 기한**: 대여일(Asia/Seoul 기준 날짜) + 14일. **1회** 연장하면 기존 기한 + 7일.
- **대여 한도**: 한 사람이 동시에 빌릴 수 있는 책은 **최대 2권**.

## 5. 요구사항

### REQ-01 도서 대여 (P0)
- 도서 목록에 제목과 남은 권수를 보여 준다.
- 로그인한 사용자는 남은 권수가 있는 책을 빌린다. 빌린 책은 "내 대여" 목록에 표시된다.
- 같은 책을 이미 빌리고 있으면 또 빌릴 수 없다.
- 대여 중인 책이 2권이면 더 빌릴 수 없다.

**인수조건**
- AC-01: 책을 빌리면 "내 대여" 목록에 표시되고 남은 권수가 1 줄어든다. 새로고침 후에도 유지된다.
- AC-02: 남은 권수가 0인 책은 "대여 불가"로 표시되고 대여 버튼이 없다.
- AC-03: 이미 빌리고 있는 책을 다시 빌리면 "이미 대여 중인 도서입니다" 오류가 표시된다.
- AC-04: 2권을 빌린 상태에서 또 빌리면 "대여 한도(2권)를 초과했습니다" 오류가 표시되고 대여되지 않는다.

### REQ-02 반납 (P0, 보안)
- 사용자는 **본인 대여만** 반납할 수 있다. 반납하면 남은 권수가 복구된다.
- API로 다른 사용자의 대여를 반납하면 **403**, 이미 반납된 대여는 **409**.
- 로그인하지 않은 요청은 **401**.

**인수조건**
- AC-05: 본인 대여를 반납하면 "내 대여"에서 사라지고 남은 권수가 복구된다. 새로고침 후에도 유지된다.
- AC-06: 다른 사용자의 대여 반납 API 요청은 403, 대여는 유지된다.
- AC-07: 이미 반납된 대여의 반납 API 요청은 409 `ALREADY_RETURNED`.
- AC-08: 비로그인 상태의 대여 API 요청은 401.

### REQ-03 반납 기한 및 연장 (P0)
- 대여하면 반납 기한(대여일 + 14일)을 "내 대여"에 표시한다.
- 본인 대여는 **1회** 연장할 수 있다 (기존 기한 + 7일).
- 다른 사용자의 대여는 연장할 수 없다 (403).

**인수조건**
- AC-09: 책을 빌리면 반납 기한이 오늘부터 14일 뒤로 표시된다.
- AC-10: 연장하면 반납 기한이 오늘부터 21일 뒤로 바뀌고, 연장 버튼이 사라진다.
- AC-11: 이미 연장한 대여를 API로 다시 연장하면 409 `ALREADY_EXTENDED`.
- AC-12: 다른 사용자의 대여 연장 API 요청은 403, 반납 기한은 그대로다.

## 6. API 계약 (초안)

| Method | Path | 설명 | 응답 |
|---|---|---|---|
| POST | /api/auth/fake-login | `{ userId }` → 세션 쿠키 | 200 |
| GET | /api/auth/me | 현재 사용자 | 200 / 401 |
| GET | /api/books | 도서 목록 (보유·남은 권수) | 200 |
| GET | /api/loans?mine=true | 내 대여 중 목록 | 200 / 401 |
| POST | /api/loans | 대여 `{ bookId }` | 201 / 400 / 401 / 404 / 409 |
| POST | /api/loans/:id/return | 반납 (본인만) | 204 / 401 / 403 / 404 / 409 |
| POST | /api/loans/:id/extend | 연장 1회 (본인만, 대여 중일 때만) | 200 / 401 / 403 / 404 / 409 |
| POST | /api/test/reset | **테스트 전용** 대여 기록 삭제 | 204 |

**오류 코드**

| 상황 | 상태 | code | message |
|---|---|---|---|
| 입력값 오류 | 400 | `VALIDATION_ERROR` | (검증 메시지) |
| 비로그인 | 401 | `UNAUTHORIZED` | 로그인이 필요합니다 |
| 본인 대여 아님 | 403 | `FORBIDDEN` | 본인 대여만 처리할 수 있습니다 |
| 남은 권수 없음 | 409 | `OUT_OF_STOCK` | 대여 가능한 재고가 없습니다 |
| 같은 책 대여 중 | 409 | `ALREADY_BORROWED` | 이미 대여 중인 도서입니다 |
| 한도 초과 | 409 | `LOAN_LIMIT_EXCEEDED` | 대여 한도(2권)를 초과했습니다 |
| 이미 반납 | 409 | `ALREADY_RETURNED` | 이미 반납된 대여입니다 |
| 이미 연장 | 409 | `ALREADY_EXTENDED` | 연장은 1회만 가능합니다 |

## 7. 비기능 요구사항
- 오류 응답 형식: `{ "error": { "code": "...", "message": "..." } }`
- **남은 권수가 1권일 때 여러 명이 동시에 빌려도 1명만 성공**한다 (재고가 음수가 되지 않는다).
- **한 사용자가 동시에 여러 책을 빌려도 대여 한도(2권)를 넘지 않는다.**
- 같은 책 중복 대여는 DB 제약으로도 막는다.
- 반납 기한은 서버가 계산한다 (클라이언트가 보낸 날짜는 쓰지 않는다). 날짜는 Asia/Seoul 기준 `YYYY-MM-DD`.
- `/api/test/reset`은 `NODE_ENV=test`일 때만 등록한다.
